Part 1: Analysis of the Website

Step 1

I chose to look at the The Tower (from 2019 to 2022). I first investigated the several inputs and outputs of the system, shown in the table below:

Input Output
Click on article title Article opens to content of article
Click “The Tower” logo on top of any page Brings user to home page
Click magnifying glass logo Search bar pops up
Click “News” in Menu Brings user to new page with a list of articles related to the news

Step 2 and 3

Next, I used Nielsen's heuristics to guide my analysis while using the system.The system has several strengths and weaknesses overall. The two top strengths of the system are:

  1. The system is very consistent. It looks and works the same way throughout all pages. The navigation bar remains on all pages which allows for easy navigation through the system. There are consistent formatting and labels which help the user feel confident in using the system. The user also can always go back to the home page through clicking the Tower logo on the top of the page which always gives the user a way out of a page. The consistency can be seen on the homepage:
  2. The system matches the real world very well. The system uses familiar labels from other news sites for categorizing the articles. This will with the user’s expectations and make for a more pleasant and easy experience. The labels are intuitive and are applied to every article, so the user knows what to expect and can consistently find the articles they want.

The top two weaknesses of the system are:

  1. The navigation and search features can be greatly improved. While the basic navigation is fine, the system lacks advanced search features to help the user find specific things. It is not possible to filter through the search by topic and date together. The system could also include features such as “related articles” to help the user explore more efficiently. By improving the search function, the site would be more efficient and user-friendly.
  2. There is a lot of visual clutter throughout the system. There are a lot of picture and banners that make it hard to focus on one item. However, the biggest clutter is the “Archives” sidebar that is on almost every page. Because it includes September 2025 to present, it goes on for very long. Part 2: Conduct a "mini-usability test"

Step 4

A friend tested the system and completed the questionaire while I made observation notes. The notes can be found in the assignment section on Brightspace.

Step 5: Comparison between heuristic analysis and the mini-usability test

Both my heuristic analysis and the mini-usability test found that the system is easy to learn and navigate initially. The system was noted to have a clear layout and a consistent look and feel. The user identified that it was quick to work and easy to understand which matches my assessment that it is a consistent site that matches the real world. Both positive assessments revolve around how the site looks and is structured.

However, both assessments also identified weaknesses in the navigation and content organization. The user who tested the system notes that topic tabs were limited and the archives were not categorized clearly, which is similar to my assessment that the system lacks advanced navigation tools. The site should be updated to have better filtering capabilities and clear connections between articles like a related article section. The archive section should also be collapsible as both me and the tester found it difficult to navigate. By improving the archive layout and navigation, the site would become more efficient and engaging for users.
